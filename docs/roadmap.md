## 0. 进度总览

| 状态 | 数量 | 含义 |
| --- | --- | --- |
| ✅ 已完成 | 40 | 已在代码中可用，无需再作为新功能排期 |
| 🟡 部分完成 | 24 | 已有基础或其中一个子项，剩余部分见说明 |
| ⬜ 未开始 | 31 | 尚未实现 |
| ⛔ 暂不排期 | 5 | 与当前产品边界冲突，见第 4 节 |

**当前判断**

- 日常播放、曲库整理、搜索、备份、车机基础广播已经形成完整闭环；但“继续播放”和独立队列历史仍缺入口，下一次打开应用还不能稳定接上上次的收听。
- 最大的剩余缺口集中在四块：**队列连续性**（多队列 / 历史 / 断点续传）、**发现与个性化**（继续播放 / 智能歌单 / 评分）、**服务端能力**（搜索合并 / InstantMix / 多端队列）、**大屏与桌面形态**（统一导航 / Android Auto）。
- 歌词全文搜索、会话日记与可靠性包刚刚落地，下一步应优先让这些数据产生日常价值，而不是继续堆独立新页面。
- 车机方向已经从"能显示"进入"稳定与多设备"阶段：队列窗口、封面开关、日志已经完成，下一步是按蓝牙设备保存配置和局域网远程控制。

## 1. 已完成能力（不再排期）

以下能力已在代码中，作为后续功能的地基：

- 本地 / WebDAV / Navidrome / Emby / 飞牛多源，服务器双地址与自动切换。
- 播放模式、队列排序、清空撤销、下一首预播放、预缓存下一首、Gapless、固定/自适应切歌过渡、A–B 循环、淡入淡出、ReplayGain、变速保持音高。
- 本地自动增量扫描、曲库体检、重复检测（仅检测）、批量标签编辑、本地删除 / 移出曲库 / 在文件夹显示。
- 搜索 2.0、A–Z 索引、曲库歌词全文搜索、久别重逢、随机列表、每日推荐与历史、首页可配置布局。
- 服务器状态页、能力探测、播放进度上报、Emby 专辑/艺术家收藏、相似艺人。
- 车机歌曲广播、歌词广播、封面广播开关、经典蓝牙封面方案、MediaSession 队列窗口、车机调试日志。
- 配置 / 歌单 / 统计备份恢复、音频输出路由页、黑胶封面、分享卡片、年度回顾、驾驶模式。
- 播放会话日记 / 音乐记忆、今日回忆、离线 scrobble 队列、同步差异预览、源健康仪表盘、本地等价曲目回退。
- 队列拖拽抬升与触觉、播放条进度与上滑队列、播放/收藏图标形变、黑胶到 mini 的收起过渡。

> 上一批已完成歌词全文搜索、播放会话日记和离线可靠性包。下面的排序优先复用这些新数据，其次补真正影响每天使用的缺口；括号内是任务池编号。

### 第一批：把会话与队列数据用起来（建议先做）

1. **DIS-01 首页“继续播放”**（🟡，S/M）
   - 范围：在首页展示最近一次未听完的会话；一键恢复队列、当前曲、进度与播放模式；没有历史时不占位。
   - 验收：冷启动进入首页可直接续播；恢复后位置误差 < 1 秒；不会覆盖用户刚建立的新队列。
   - 依赖：REL-09 已完成，主要剩首页卡片和状态回填。

2. **REL-03 队列历史 / 多套队列**（🟡，M）
   - 范围：保留最近 N 套队列，支持命名 / 固定 / 切换；清空撤销并入历史；临时插歌不污染原队列。
   - 验收：重启后历史仍在；切回旧队列当前曲和进度正确；连续切换不丢数据。
   - 依赖：队列持久化结构升级；会话快照已能复用。

3. **DIS-06 队列医生**（⬜，S）
   - 范围：一键去重、移除已播、合并同专辑、保留下一段，并提供撤销。
   - 验收：当前曲不被误删；整理结果可预览；撤销能恢复原顺序。
   - 依赖：现有队列逻辑，不需要新服务。

### 第二批：可靠性、搜索与发现

4. **REL-04 下载断点续传 + 离线钉选**（🟡，M）
   - 范围：HTTP Range 续传、失败退避、永久保留不参与 LRU；暂停 / 杀进程后可继续。
   - 验收：不重复下载已完成字节；钉选歌曲永不被缓存上限清掉；失败可手动重试。
   - 依赖：DownloadManager、缓存淘汰与缓存预算页。

5. **SRV-02 服务端搜索合并**（⬜，M）
   - 范围：本地结果先出，服务器 `search3` / Emby SearchTerm 异步合并、去重并标记来源；失败不阻塞本地结果。
   - 验收：本地未同步时也能搜到服务器歌曲；重复结果只保留一条；不支持的服务不显示入口。
   - 依赖：SRV-01 能力探测、现有搜索页异步化。

6. **DIS-04 Instant Mix / 相似队列**（🟡，M）
   - 范围：按当前歌曲生成相似队列；优先服务端 `getSimilarSongs` / InstantMix，失败时用本地流派 / 年代 / 艺人回退。
   - 验收：不支持的服务隐藏入口；生成队列不中断当前播放；可撤销。
   - 依赖：能力探测、相似艺人数据、本地元数据。

### 第三批：曲库维护闭环

7. **LIB-11 / LIB-03 音乐库维护中心**（⬜ / 🟡，M）
   - 范围：把体检、缺封面 / 歌词、重复、命名、整理集中到一个入口；支持任务队列与失败重试。
   - 验收：每个体检项都能直接执行修复；不静默改文件；可取消。
   - 依赖：现有刮削、封面、歌词、整理工具。

8. **LIB-12 重复歌曲清理**（🟡，M）
   - 范围：在现有分组基础上支持保留一首、批量移出曲库、按路径 / 音质选择保留项。
   - 验收：不会误删仍在播放 / 队列中的歌曲；操作必须二次确认。
   - 依赖：重复检测、本地删除 / 移出曲库。

9. **LIB-06 单文件夹重扫**（⬜，S）
   - 范围：文件夹详情只重扫当前目录；新增专辑后不必全库扫描。
   - 验收：只更新该目录下的新增 / 删除 / 改名；进度可见。
   - 依赖：现有增量扫描。

### 第四批：车机与歌词增强

10. **CAR-02 按蓝牙设备保存车机配置**（⬜，M）
    - 范围：按当前输出设备保存行数、字段、封面方案；不同车自动切换，未知设备用默认值。
    - 验收：两辆车来回连接不互相覆盖；配置切换不需要重启播放。
    - 依赖：AUD-04 路由信息、广播配置结构。

11. **CAR-04 局域网 Web 遥控**（⬜，M）
    - 范围：同一 Wi-Fi 下浏览队列、切歌、暂停、搜索；只读状态 + 有限写操作，token 鉴权。
    - 验收：断线自动重连；不暴露公网；不改变当前音频路由。
    - 依赖：BroadcastInspector 端口、HTTP / SSE、队列版本。

12. **LYR-01 + LYR-03 歌词体验**（🟡 / ⬜，S/M）
    - 范围：翻译全局开关与语言选择；当前行循环 / 单行 A–B 练习；退出播放器自动取消。
    - 验收：关闭翻译不占行高；循环区间可拖动；不与全曲 A–B 冲突。
    - 依赖：现有 `translates`、行时间、A–B 循环。

**如果只做一批**：优先 1、2、3。它们全部复用现有队列 / 会话数据，能在最短时间内让“继续听”和“整理队列”变成日常闭环。

## 4. 暂不做的批次

以下方向价值明确，但要么成本过高，要么会破坏当前产品边界，暂不排期：

- **双轨重叠交叉淡化**：REL-02 已提供固定/自适应顺序淡入淡出；真正的双轨叠加需要第二播放器与媒体会话交接，暂不排期。
- **AUD-07 USB / DSD bit-perfect**：需要自定义 USB 音频驱动，不是插件级工作。
- **CAR-05 听歌房 / 共享队列**：需要账号、权限、审核与局域网服务，先做 CAR-04 遥控。
- **UI-03 统一外壳**：影响全部页面，适合单独一个版本专门做。
- **REL-13 / CAR-06 Android Auto / CarPlay**：平台原生工程量大，先用现有 MediaSession + 队列窗口覆盖。

## 5. 明确边界

- 不做 iOS 专属新功能；iOS 仅维持现有可用能力。
- 不接入酷狗等其他抓取源；刮削仍只走网易云与 QQ。
- 不把服务器可写能力当作默认前提：所有服务端功能先能力探测，不支持就不显示入口。
- 不静默删除用户文件：删除/移出曲库必须二次确认，并区分“只删记录”和“删文件”。
- 不把密码写进备份文件；备份恢复只恢复地址，密码重新输入。
- 不提交路线图文档本身；路线图只用于本地规划。

## 7. 验收指标（下一阶段）

- 播放：相邻曲目静音缝 < 50 ms；队列恢复位置误差 < 1 s。
- 会话：恢复队列后当前曲与进度误差 < 1 s；连续播放完成比例与日记一致。
- 下载：断点续传不重复下载已完成字节；钉选歌曲淘汰率 0。
- 搜索：本地结果首屏 < 150 ms；歌词 FTS 首屏 < 300 ms；服务器结果不阻塞本地首屏。
- 可靠性：离线上报重试不重复、不丢失；同步预览计数与实际 apply 一致。
- 源健康：单源探测可取消，失败不影响播放与本地搜索。
- 车机：切歌元数据延迟 < 1 s；队列位置与 App 一致；封面开关关闭后无封面请求。
- 曲库：同一歌曲在专辑/艺术家页只出现一次；同名专辑按艺术家分开。
- 稳定性：`flutter analyze` 0 error；核心测试全绿。
